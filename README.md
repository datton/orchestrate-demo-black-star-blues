# black-star-blues.demo.orchestrate.ca

Built live by the Orchestrate Solutions agent team in an Orchestrate demonstration. Static site: HTML, CSS and JavaScript.

## About

An independent fan site in Ghanaian colours (red, gold and green, with the black star) for Ghanaian Chelsea supporters in England. It is not affiliated with or endorsed by any football club. It uses no club crest, logos or official photos, and shows no live scores.
